# Traduzir a interface (pt / en / fr)

A língua é escolhida em **Definições → Idioma** (e no menu da conta / ecrã de login). Fica guardada no dispositivo (`localStorage` `bap.lang`). Mudar de língua volta a montar a app, por isso uma chamada simples a `t()` lê sempre a língua atual.

## Como funciona

```ts
import { t, L, locale, fmtDate } from "@/lib/i18n";

t("Apagar jogo")                         // "Delete game" / "Supprimer le match"
t("{n} eventos", { n: 12 })              // variáveis entre chavetas
n === 1 ? t("{n} jogo", { n }) : t("{n} jogos", { n })   // plurais: duas chaves
new Date(x).toLocaleDateString(locale(), { day: "numeric", month: "short" })
```

- **A chave é o texto em português**, exatamente igual (pontuação, reticências `…`, emoji).
- Traduções em `src/i18n/parts/<área>.ts` (`en` e `fr` lado a lado). Se faltar uma tradução aparece o português.
- Verificar: `npx tsx --tsconfig tsconfig.json scripts/i18n-check.ts` (e `--suspects` para ver texto em português que ficou por embrulhar).

## Regras

1. Embrulhar **todo o texto que o utilizador vê**: texto JSX, `placeholder`, `title`, `aria-label`, `alt`, mensagens de `ask()`/`notify()`, toasts, erros mostrados, texto gerado em `lib/` (relatórios, insights, sugestões), textos para WhatsApp/partilha, títulos e corpo das notificações, texto desenhado em canvas.
2. `t()` só recebe **uma string literal entre aspas duplas** como 1.º argumento (sem template literals). Partes variáveis → `{nome}`.
3. **Nunca chamar `t()` ao nível do módulo** (constantes avaliadas no import ficariam presas numa língua). Em constantes usa `L("Texto")` (só marca a string) e traduz ao mostrar: `t(item.label)`.
4. **Não traduzir**: valores guardados na base de dados ou usados como id/chave/comparação (tipos de evento `"SHOT"`, estados, etc.), classes CSS, URLs, `console.*`, comentários, dados do utilizador. Se uma string em português é usada como chave E mostrada, traduz só no sítio onde é mostrada.
5. Datas e horas: trocar `"pt-PT"` por `locale()`.
6. Uma variável local chamada `t` esconde a função: renomear (`teams.map((tm) => …)`).
7. Frases com elementos JSX no meio (`<strong>`, links): dividir em pedaços `t()` que façam sentido sozinhos, ou reescrever a frase.
